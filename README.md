# MediConnect Health — ISO/IEC 27001 ISMS Project

## Project Overview

This project documents the development of a simulated Information Security Management System (ISMS) for MediConnect Health, a fictional healthcare technology company.

The purpose of this project is to gain practical experience applying information security governance, risk management, compliance, and control concepts within a simulated business environment.

The ISMS is being developed using ISO/IEC 27001 as the primary framework.

## Business Scenario

MediConnect Health is a fictional healthcare technology company with approximately 150 employees.

The organization operates a cloud-hosted patient portal that allows patients to:

- View medical information
- Schedule appointments
- Communicate with healthcare providers
- Upload medical documents
- Update personal information

Because MediConnect processes sensitive information, including Protected Health Information (PHI) and Personally Identifiable Information (PII), the organization has decided to establish an ISO/IEC 27001-aligned Information Security Management System.

## Project Objectives

The objectives of this project are to:

- Establish the scope of the ISMS
- Identify and assess information security risks
- Develop a risk treatment process
- Evaluate applicable security controls
- Create a Statement of Applicability (SoA)
- Develop supporting information security policies
- Perform sample control assessments
- Document audit findings and corrective actions
